# Независимый чекер адресов восстановления (инцидент Keplr / Web3Auth, ноябрь 2026)

Статический сайт без сборки и бэкенда. Неофициальный, не связан с Keplr/Web3Auth/Consensys.

## Запуск
`python3 -m http.server 8000` в этой папке → http://localhost:8000. Тесты: `node --test test/checker.test.js` (Node 18+).

## Деплой на GitHub Pages
Залить файлы в корень репозитория → Settings → Pages → Deploy from branch `main` / root. Никаких секретов не нужно.

## Что делает
1. Проверяет bech32 (формат + контрольную сумму), определяет сеть по префиксу. Не исправляет адреса.
2. Для сети запрашивает `GET {REST}/cosmos/tx/v1beta1/txs?query=message.sender='<адрес>'` постранично (50 × до 20 страниц, count_total) и ищет **упоминание** адреса из списка в любом строковом поле tx. Для каждого упоминания показывается, где оно (сообщение / memo / событие / другое), и успешна ли tx (code 0) или неуспешна. **Это не подтверждение перевода средств**: направление и сумма не проверяются; адрес может быть в memo или в несвязанном событии. Неуспешные tx явно помечаются «не перевод». Для Injective также ищется EVM-адрес.
3. Проверяет хранение истории узла (`/cosmos/base/tendermint/v1beta1/blocks/...`): если узел не хранит блоки до 06.11.2026 — «неполная проверка».
4. Опционально — адреса с теми же 20 байтами в других сетях списка (кроме Injective). Это не доказывает, что кошелёк пользователя использует там этот адрес: зависит от пути деривации.
5. Резервный режим: локальный поиск адресов списка во вставленном JSON/тексте транзакции.

Статусы: «адрес упоминается» (с разбивкой успешные/неуспешные) / «в полученных транзакциях совпадений нет; полнота индекса узла не гарантируется» / неполная (лимит страниц, total > просмотрено, обрезанная история) / ошибка. Ошибка ≠ «нет совпадений».

## Ограничения
- Не видит переводы, где адрес пользователя не `message.sender` (напр. authz-грантополучатель без адреса в sender — хотя MsgExec подписан грантополучателем), многоходовые маршруты, транзакции старше последних 1000 от адреса.
- Наличие блоков на узле ≠ гарантия полноты индекса транзакций.
- EVM: «8 сетей» не перечислены в доступных источниках — только ссылка на blockscan.com, без автопроверки.
- Отсутствие совпадений не значит «кошелёк безопасен»; другие получатели не помечаются как злоумышленники; совпадение не гарантирует возврат.
